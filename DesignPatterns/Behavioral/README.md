# Behavioral Patterns

Behavioral patterns describe how objects share work and respond to requests or changes.

| Pattern | Use it to | Guide |
|---|---|---|
| Strategy | Switch between interchangeable algorithms | [Strategy](Strategy/README.md) |
| Observer | Notify subscribers when a subject changes | [Observer](Observer/README.md) |
| Iterator | Traverse a collection through a common interface | [Iterator](Iterator/README.md) |
| Command | Represent a request as an object | [Command](Command/README.md) |
| Mediator | Coordinate communication through a central object | [Mediator](Mediator/README.md) |
| State | Change an object's behavior as its state changes | [State](State/README.md) |

Chain of Responsibility, Memento, Template Method, Visitor, and Interpreter do not yet have examples here. Each implemented pattern folder lists its source files and how to run them.
