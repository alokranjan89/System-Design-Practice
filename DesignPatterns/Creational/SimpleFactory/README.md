# Factory Pattern Examples

This folder contains three C++ examples related to factory patterns.

Files:
- `simple_factory.cpp` — a basic factory function example.
- `factory_method.cpp` — the factory method pattern with separate creator classes.
- `abstract_factory.cpp` — abstract factory pattern with product families.

Key concepts:
- Encapsulating object creation
- Decoupling client code from concrete classes
- Extending creation logic without modifying the client

How to run:
- Compile one of the example files.
- Run the resulting executable.
