# YAGNI Principle

YAGNI means "You Aren't Gonna Need It."

## Meaning

Do not build features before they are actually required.

## What this example shows

- Implement only the current requirement.
- Avoid future features that are not asked for.
- Keep the codebase smaller and easier to maintain.

## Advantages

- Saves development time.
- Reduces unused code.
- Lowers maintenance cost.
- Helps keep the design focused.

## Disadvantages

- Some future changes may require refactoring.
- It requires discipline to avoid guessing future requirements.

## How to run

```powershell
cd "System Design\Principles\YAGNI"
g++ -std=c++17 -Wall -Wextra yagni.cpp -o yagni.exe
./yagni.exe
```
