# Design Principles

Principles are practical guidance for making code easier to understand and change. Learn the basics before reaching for a design pattern.

| Topic | Core idea | Guide |
|---|---|---|
| KISS | Prefer a simple solution that meets the requirement | [KISS](KISS/README.md) |
| DRY | Keep one authoritative source for each piece of knowledge | [DRY](DRY/README.md) |
| YAGNI | Avoid speculative features | [YAGNI](YAGNI/README.md) |
| SOLID | Five principles for object-oriented design | [SOLID](Solid/README.md) |

These are guidelines, not rules to apply mechanically. For example, Strategy can help keep new behaviors extensible, but adding an interface for a single fixed behavior may only add complexity.
