# SOLID Principles

This folder contains examples for several SOLID principles:
- `single_responsibility.cpp` - Single Responsibility Principle
- `open_closed.cpp` - Open/Closed Principle
- `liskov_substitution.cpp` - Liskov Substitution Principle
- `interface_segregation.cpp` - Interface Segregation Principle
- `dependency_inversion.cpp` - Dependency Inversion Principle

Key concepts:
- Keep classes focused
- Extend behavior without modifying existing code
- Avoid incorrect inheritance hierarchies
- Separate interfaces based on responsibilities
- Depend on abstractions instead of concrete implementations

How to run:
- Compile any of the example files.
- Run the resulting executable.
